# Azy Programming Language

**Azy** — это разрабатываемый компилируемый язык программирования общего назначения, создаваемый с нуля на C++.

---

## 📌 Текущий прогресс разработки

На данный момент полностью разработан и отлажен **лексический анализатор (лексер)** и частично **синтаксический анализатор (парсер)**. Лексер преобразует исходный код в последовательность токенов, а парсер использует метод рекурсивного спуска для разбора грамматики языка.

### Возможности текущего лексера:

* **Типизация токенов (`TokenType`):** поддержка идентификаторов (`Identifier`), целых чисел (`Int`), чисел с плавающей точкой (`Float`), строк (`String`), операторов (`Operator`) и неизвестных символов (`Unknown`).
* **Продвинутая обработка чисел:** корректный разбор целых чисел, чисел с плавающей точкой (например, `3.14`), чисел, начинающихся с точки (`.5`), а также безопасное распознавание одиночной точки как оператора.
* **Строковые литералы и комментарии:** выделение текста в кавычках (`"..."`) и автоматический пропуск однострочных комментариев (`#`).
* **Составные операторы:** распознавание сложных логических операторов и сравнения (`==`, `!=`, `<=`, `>=`, `&&`, `||`).
* **Трекинг позиций:** точное определение номера строки и колонки для отладки.

### Возможности текущего парсера (интерпретатор выражений и управляющих конструкций):

* **Рекурсивный спуск с предпросмотром:** использование методов `peek`, `peekNext`, `check` и `checkNext` для безопасного анализа кода на лету.
* **Управляющие конструкции:**
* Условные ветвления (`if / else` с поддержкой каскадных `else if`).
* Циклы с предусловием (`while (...) { ... }`).
* Циклы с постусловием (`do { ... } while (...)`).
* Изолированные блоки кода (`{ ... }`).


* **Операции присваивания:** распознавание выражений вида `переменная = правая_часть`.
* **Строгая иерархия приоритетов выражений и условий (снизу вверх):**
1. Логическое ИЛИ (`||`)
2. Логическое И (`&&`)
3. Операторы равенства (`==`, `!=`)
4. Операторы сравнения (`<`, `>`, `<=`, `>=`)
5. Сложение и вычитание (`+`, `-`)
6. Умножение и деление (`*`, `/`)
7. Унарные операторы (`!`, `not`, `-`)
8. Базовые литералы, переменные и вложенные скобки `(...)`.


* **Продвинутая система ошибок (`parserError`):** вывод понятных диагностических сообщений с указанием строки, символа и контекста сбоя.

## 📂 Структура проекта

```text
AZY/
├── Application/         # Собранные бинарники и тестовые скрипты
│   ├── AZY_compiler
│   └── test.azy
├── src/                 # Исходный код компилятора
│   ├── lexer.cpp        # Реализация лексического анализатора
│   ├── lexer.h          # Интерфейс лексера
│   ├── parser.cpp       # Реализация синтаксического анализатора
│   ├── parser.h         # Интерфейс парсера
│   ├── Token.h          # Определение структуры Token и перечисления TokenType
│   └── main.cpp         # Точка входа (потоковый вывод токенов в консоль)
├── trash/               # Архивные и черновые наработки
└── CMakeLists.txt       # Конфигурация сборки CMake

```

## 🛠 Сборка и запуск проекта

Для сборки проекта требуются компилятор с поддержкой **C++17** и система сборки **CMake** (версии 3.10 и выше).

### Клонирование и компиляция:

```bash
# Клонирование репозитория
git clone https://github.com/Azyholl-Lab/Azy.git
cd Azy

# Создание директории сборки
mkdir build
cd build

# Генерация файлов сборки и компиляция
cmake ..
cmake --build .

```

### Запуск анализатора:

После успешной сборки исполняемый файл можно запустить двумя способами:

1. **Интерактивный ввод из консоли** (для проверки кода «на лету»):
```bash
cd ../Application/
./AZY_compiler

```
*(После запуска можно вводить код прямо в терминале, а для завершения ввода использовать комбинацию `Ctrl+C`)*.


2. **Анализ файла с исходным кодом**:
```bash
cd ../Application/
./AZY_compiler test.azy

```
